## Common Type Issues and Solutions

### Issue 1: Stale Types

**Symptom**: TypeScript doesn't see new fields
**Solution**:
```bash
# Delete generated files
rm -rf node_modules/.prisma
rm -rf .next

# Regenerate
npx prisma generate
npm run dev  # Restart dev server
```

### Issue 2: Manual Receipt Type Out of Sync

**Symptom**: Type error about missing fields
**Solution**: Extend Prisma type instead of manual definition
```typescript
// ❌ Bad
export interface Receipt {
  id: string
  // ... manual fields (will get out of sync)
}

// ✅ Good
import { Receipt as PrismaReceipt } from '@prisma/client'
export type Receipt = PrismaReceipt
// OR add frontend-only fields
export interface Receipt extends PrismaReceipt {
  isSelected?: boolean  // Frontend-only
}
```

### Issue 3: Decimal Type Errors

**Symptom**: `Type 'Decimal' is not assignable to type 'number'`
**Solution**: Convert Decimal to number explicitly
```typescript
const confidence = receipt.duplicateConfidence
  ? Number(receipt.duplicateConfidence)
  : null
```
